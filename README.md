# 两轴步进电机控制方案

基于西门子 S7-200 SMART ST60 的两轴步进电机控制方案，用于对 X 轴 / Y 轴传送带进行定位与手动控制。

## 项目用途

- 控制两个步进电机（SUMTOR 57HS11242B4D8SC），分别驱动 X 轴、Y 轴传送带。
- 每轴带一个带电永磁制动器（通电释放、失电抱闸），程序内置「先松闸 → 延时确认 → 再放行运动」的时序。
- 每轴带一个 NPN 型原点传感器（ZM-Y45），实现严格顺序回原点（X 轴先回，完成后 Y 轴再回）。
- 内置回原点超时与报错复位保护，入口采用常闭停止 / 急停。

## 硬件与 I/O 概要

- PLC：S7-200 SMART CPU ST60（DC/DC/DC，36DI / 24DO 晶体管输出）。
- 脉冲 / 方向 / 使能：Axis0 = Q0.0(脉冲) / Q0.2(方向) / Q0.4(使能)；Axis1 = Q0.1 / Q0.7 / Q0.5。
- 抱闸输出：Q1.0(X) / Q1.1(Y)，经中间继电器驱动。
- 原点输入：I0.4(X) / I0.5(Y)，NPN 接法（输入公共端 1M / 2M 接 +24V）。
