================================================================
两轴步进电机控制程序清单
西门子 S7-200 SMART ST60  ·  梯形图(STL)照抄清单
================================================================

【使用说明】
1. 纯继电器/定时器/比较网络(网络1~3、6~8、11~13、16)：
   在 STEP 7 Micro/WIN SMART 的"程序块"编辑器切换到 STL 视图，
   逐行输入后切换回 LAD 视图即自动转为梯形图。
2. AXISx_* 为运动向导生成的运动指令：
   在 LAD 视图下从"指令树→调用子程序"拖入对应 AXISx_CTRL/RSEEK/
   MAN/GOTO 指令盒，再按下方引脚说明接线即可(勿在 STL 中手打)。

----------------------------------------------------------------
【变量 / 标志表】
----------------------------------------------------------------
M0.0   运行标志
M0.3   连续运行 RUN(备用，接 0)
M0.4   手动方向选择(备用，接 0)
M0.5   X 轴手动方向(输出)
M0.6   Y 轴手动方向(输出)
M0.7   运动允许(抱闸已松开)
M1.0   X CTRL Done
M1.1   X CTRL C_Dir
M1.2   Y CTRL Done
M1.3   Y CTRL C_Dir
M2.0   回原点请求(自锁)
M2.1   X 轴回原点阶段
M2.2   Y 轴回原点阶段
M2.3   回原点完成指示
M2.4   回原点故障
M3.0   定位启动脉冲
M3.1   X GOTO Abort
M3.2   X GOTO Done
M3.3   Y GOTO START
M3.4   Y GOTO Abort
M3.5   Y GOTO Done
M4.0   X 寻原点完成(RSEEK Done)
M4.1   Y 寻原点完成(RSEEK Done)

T37    回原点超时定时(100ms×50=5s)
T38    抱闸松开确认延时(100ms×3=300ms)

VB100  X CTRL 错误       VD104  X 当前位
VB102  Y CTRL 错误       VD108  X 当前速度
VB110  X RSEEK 错误      VD204  Y 当前位
VB120  Y RSEEK 错误      VD208  Y 当前速度
VB140  X MAN 错误        VD130  X 点动速度
VB240  Y MAN 错误        VD230  Y 点动速度
VB150  X GOTO 错误       VD300  X 定位目标位
VB250  Y GOTO 错误       VD310  X 定位速度
VD144  X 手动当前位      VD400  Y 定位目标位
VD148  X 手动当前速度    VD410  Y 定位速度
VD154  X GOTO 当前位     VD254  Y GOTO 当前位
VD158  X GOTO 当前速度   VD258  Y GOTO 当前速度
VD244  Y 手动当前位
VD248  Y 手动当前速度

----------------------------------------------------------------
【输入/输出 I/O】
----------------------------------------------------------------
I0.0 启动(常开)   I0.1 停止(常闭)   I0.2 急停(常闭)
I0.3 回原点       I0.4 X原点NPN    I0.5 Y原点NPN
I0.6 X正点动      I0.7 X反点动     I1.0 Y正点动
I1.1 Y反点动      I1.2 定位触发     I1.3~ 备用
Q0.0 X脉冲  Q0.1 Y脉冲  Q0.2 X方向  Q0.7 Y方向
Q0.4 X使能  Q0.5 Y使能  Q1.0 X抱闸   Q1.1 Y抱闸

================================================================
【程序】  (共 18 个网络)
================================================================

-------- 网络1 首次扫描初始化：赋点动/定位速度 --------
LD   SM0.1
MOVD 4000,  VD130     // X手动点动速度(脉冲/s)
MOVD 4000,  VD230     // Y手动点动速度
MOVD 20000, VD310     // X定位速度
MOVD 20000, VD410     // Y定位速度

-------- 网络2 运行标志自锁：启动/停止/急停 --------
LD   I0.0             // 启动(常开)
O    M0.0             // 自锁
A    I0.1             // 停止(常闭按钮)
A    I0.2             // 急停(常闭按钮)
=    M0.0             // 运行标志

-------- 网络3 抱闸释放与运动允许(先松闸→延时→再允许) --------
LD   M0.0             // 运行标志
=    Q1.0             // X抱闸释放
=    Q1.1             // Y抱闸释放
TON  T38, +3          // 松开确认延时 100ms×3=300ms
LD   T38              // 延时到(已机械松开)
=    M0.7             // 运动允许标志

-------- 网络4 X轴控制使能(MOD_EN 受运动允许 M0.7 门控) --------
[AXIS0_CTRL 指令盒]
  EN     = SM0.0
  MOD_EN = M0.7
  Done→M1.0   Error→VB100   C_Pos→VD104   C_Speed→VD108   C_Dir→M1.1

-------- 网络5 Y轴控制使能(MOD_EN 受运动允许 M0.7 门控) --------
[AXIS1_CTRL 指令盒]
  EN     = SM0.0
  MOD_EN = M0.7
  Done→M1.2   Error→VB102   C_Pos→VD204   C_Speed→VD208   C_Dir→M1.3

-------- 网络6 回原点请求(上升沿/运动允许/空闲) --------
LD   I0.3             // 回原点按钮
EU                    // 上升沿
A    M0.7             // 运动允许(抱闸已松开)
AN   M2.0             // 不在回原点中
S    M2.0, 1          // 置位请求
R    M2.3, 1          // 清上次完成标志
R    M2.4, 1          // 清回原点故障标志
S    M2.1, 1          // 进入X阶段→启动AXIS0_RSEEK

-------- 网络7 状态推进：X完成→启动Y --------
LD   M4.0             // X寻原点完成
A    M2.1             // 且仍处X阶段
R    M2.1, 1          // 退出X阶段
S    M2.2, 1          // 进入Y阶段→启动AXIS1_RSEEK

-------- 网络8 状态推进：Y完成→结束 --------
LD   M4.1             // Y寻原点完成
A    M2.2             // 且仍处Y阶段
R    M2.2, 1          // 退出Y阶段
R    M2.0, 1          // 复位请求
S    M2.3, 1          // 置位完成指示

-------- 网络9 X轴寻原点 --------
[AXIS0_RSEEK 指令盒]
  EN    = SM0.0
  START = M2.1
  Done→M4.0   Error→VB110

-------- 网络10 Y轴寻原点 --------
[AXIS1_RSEEK 指令盒]
  EN    = SM0.0
  START = M2.2
  Done→M4.1   Error→VB120

-------- 网络11 回原点出错复位(X/Y任一Error非零) --------
LD   M2.0             // 回原点请求中
AB<> VB110, 0         // 且X错误非零
LD   M2.2             // 或：Y阶段
AB<> VB120, 0         // 且Y错误非零
OLD                   // 两分支取"或"
S    M2.4, 1          // 置位故障标志
R    M2.0, 1          // 复位请求
R    M2.1, 1          // 退出X阶段
R    M2.2, 1          // 退出Y阶段

-------- 网络12 回原点超时定时(5s) --------
LD   M2.0             // 回原点进行中
TON  T37, +50         // 100ms×50 = 5s

-------- 网络13 超时故障复位 --------
LD   T37              // 定时到(超时)
S    M2.4, 1          // 置位故障标志
R    M2.0, 1
R    M2.1, 1
R    M2.2, 1

-------- 网络14 X轴手动点动 --------
[AXIS0_MAN 指令盒]
  EN    = SM0.0
  RUN   = M0.3(0)
  JOG_P = I0.6
  JOG_N = I0.7
  Speed = VD130
  Dir   = M0.4
  Error→VB140   C_Pos→VD144   C_Speed→VD148   C_Dir→M0.5

-------- 网络15 Y轴手动点动 --------
[AXIS1_MAN 指令盒]
  EN    = SM0.0
  RUN   = M0.3(0)
  JOG_P = I1.0
  JOG_N = I1.1
  Speed = VD230
  Dir   = M0.4
  Error→VB240   C_Pos→VD244   C_Speed→VD248   C_Dir→M0.6

-------- 网络16 定位触发(受运动允许 M0.7 门控) --------
LD   I1.2             // 定位按钮
EU
A    M0.7
=    M3.0

-------- 网络17 X轴定位到目标位置 --------
[AXIS0_GOTO 指令盒]   // Mode=0绝对,1相对
  EN    = SM0.0
  START = M3.0
  Pos   = VD300
  Speed = VD310
  Mode  = 0
  Abort = M3.1
  Done→M3.2   Error→VB150   C_Pos→VD154   C_Speed→VD158

-------- 网络18 Y轴定位到目标位置 --------
[AXIS1_GOTO 指令盒]   // Mode=0绝对,1相对
  EN    = SM0.0
  START = M3.3
  Pos   = VD400
  Speed = VD410
  Mode  = 0
  Abort = M3.4
  Done→M3.5   Error→VB250   C_Pos→VD254   C_Speed→VD258

================================================================
备注：
- 故障标志 M2.4 可接报警：LD M2.4 = Q1.2。
- 回原点超时时长改 T37 设定值即可。
- 抱闸松开确认延时改 T38 设定值(默认 300ms)。
