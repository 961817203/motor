==================================================
S7-200 SMART ST60 · 两轴步进电机控制
纯 STL 粘贴版（仅含可在 STL 视图直接输入的普通逻辑）
==================================================

【使用说明】
1. 打开 STEP 7-Micro/WIN SMART 主程序块(OB1)，切换到 STL 视图。
2. 下面每个 "NETWORK n" 为一段（一个梯级），逐段粘贴即可；
   整段粘贴时编辑器若识别 NETWORK 关键字会自动生成多个网络。
3. 以 // 开头的行是注释，粘贴安全；如个别版本报错可删掉注释行。
4. 运动指令 AXISx_CTRL / RSEEK / MAN / GOTO 不在此列，需先跑完
   运动向导生成符号，再以“指令盒”拖入 LAD 接线（见方案文档）。

--------------------------------------------------
以下为可粘贴的 STL 逻辑（共 11 个梯级）
--------------------------------------------------

NETWORK 1
// 首次扫描初始化：赋点动/定位速度
LD     SM0.1
MOVD   4000,  VD130
MOVD   4000,  VD230
MOVD   20000, VD310
MOVD   20000, VD410

NETWORK 2
// 运行标志自锁：启动/停止/急停
LD     I0.0
O      M0.0
A      I0.1
A      I0.2
=      M0.0

NETWORK 3
// 抱闸释放并启动松开确认延时 T38
LD     M0.0
=      Q1.0
=      Q1.1
TON    T38, +3

NETWORK 4
// 运动允许标志（抱闸已松开）
LD     T38
=      M0.7

NETWORK 5
// 回原点请求
LD     I0.3
EU
A      M0.7
AN     M2.0
S      M2.0, 1
R      M2.3, 1
R      M2.4, 1
S      M2.1, 1

NETWORK 6
// X 寻原点完成 -> 启动 Y 寻原点
LD     M4.0
A      M2.1
R      M2.1, 1
S      M2.2, 1

NETWORK 7
// Y 寻原点完成 -> 回原点结束
LD     M4.1
A      M2.2
R      M2.2, 1
R      M2.0, 1
S      M2.3, 1

NETWORK 8
// 回原点出错复位
LD     M2.0
AB<>   VB110, 0
LD     M2.2
AB<>   VB120, 0
OLD
S      M2.4, 1
R      M2.0, 1
R      M2.1, 1
R      M2.2, 1

NETWORK 9
// 回原点超时定时（5s）
LD     M2.0
TON    T37, +50

NETWORK 10
// 超时故障复位
LD     T37
S      M2.4, 1
R      M2.0, 1
R      M2.1, 1
R      M2.2, 1

NETWORK 11
// 定位触发（受运动允许门控）
LD     I1.2
EU
A      M0.7
=      M3.0

==================================================
对应关系：
- 文档/完整程序中的“网络”与本粘贴版梯级一致，
  其中原网络3(抱闸)在此拆成 NETWORK 3 与 NETWORK 4 两个梯级。
- 运动指令盒需另拖（X轴/Y轴各4个）：CTRL、RSEEK、MAN、GOTO。
